## 🔑 Key Components

### Ingestion Layer (`ingestion/`)

Copy file from local folder, preprocess "ExSD-*.xls" files by remove unwanted sheets and save them
Extract data from file and load as csv

### Transformation Layer(Sqlmesh[duckdb])

Cleaned and model data using Medallion architecture: Bronze(Raw), Silver(Staging), Gold(Marts)
and writing parquet file using ducklake with a duckdb database as catalog

### Serving

Copy Gold(marts) data to a serving duckdb database for Bi tools to connect and consume

### Orchestration (Dagster)
Orchestrate the whole pipeline using dagster
